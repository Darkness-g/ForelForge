Курсовая работа: ForelForge – Веб-платформа для загрузки, покупки и управления играми

1. Название проекта

ForelForge – это веб-приложение для публикации, покупки и управления играми пользователями и администраторами.

2. Цель проекта

Целью данной курсовой работы является создание интерактивной платформы для:

Разработчиков игр — загрузка игр и их обложек, просмотр статуса проверки.
Пользователей — просмотр рекомендованных игр, покупка и управление библиотекой.
Администраторов — проверка загруженных игр, одобрение или отклонение публикаций.

Проект демонстрирует навыки работы с Python, Flask, SQL Server, HTML, CSS и базовыми принципами веб-разработки.

3. Основные возможности приложения

3.1 Для пользователей
Регистрация и авторизация с сессиями.
Просмотр главной страницы с рекомендациями игр.
Просмотр каталога всех доступных игр.
Детальная информация по каждой игре (описание, цена, разработчик, дата релиза).
Покупка игр с учётом баланса.
Управление библиотекой купленных игр.
Возможность скачивания приобретённых игр.
Просмотр и редактирование профиля, смена аватарки.
Пополнение баланса через форму.

3.2 Для разработчиков
Загрузка новых игр с файловой поддержкой форматов zip, exe, rar.
Добавление обложек для игр (форматы jpg, png, jpeg, gif).
Автоматическое сохранение игр как “pending” до проверки администратором.

3.3 Для администраторов
Просмотр всех загруженных игр со статусом “pending”.
Одобрение или отклонение новых игр.
Перемещение одобренных игр и обложек в отдельную директорию “approved”.
Управление базой данных игр и пользователей (опционально через интерфейс).


4. Структура проекта

app.py — основной скрипт Flask-приложения с роутами и логикой.
templates/ — HTML-шаблоны для всех страниц (index.html, games.html, upload_game.html и др.).
static/ — статика: CSS, изображения, загруженные игры и обложки.
uploads/ — директория для загруженных файлов игр и изображений.
database.sql — скрипт для создания базы данных и таблиц.


5. Используемые технологии
Python 3.x — серверная логика и обработка запросов.
Flask — микрофреймворк для веб-приложения.
PyODBC — взаимодействие с базой данных SQL Server.
SQL Server — хранение информации о пользователях, играх и покупках.
HTML, CSS — фронтенд приложения.
Werkzeug — работа с безопасными именами файлов.


6. Установка и запуск
Клонировать проект или скачать архив.

Создать виртуальное окружение:

python -m venv .venv
Активировать виртуальное окружение:

Windows: .venv\Scripts\activate
Linux/Mac: source .venv/bin/activate

Установить зависимости:

pip install flask pyodbc
Настроить подключение к SQL Server в app.py.

Создать необходимые папки:

static/uploads/games
static/uploads/images
static/uploads/approved

Запустить приложение:

python app.py
Перейти в браузер по адресу: http://127.0.0.1:5000/.


7. Особенности реализации
Система ролей: user, admin.
Игры загружаются в папку uploads и сохраняются в БД как относительный путь.
Рекомендации игр реализованы с горизонтальной прокруткой для удобного просмотра.
Описание игр ограничено по длине для аккуратного отображения.
Дефолтные изображения для игр и аватаров, если пользователь или игра не добавили свои.
